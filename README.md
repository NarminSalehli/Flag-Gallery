Flag Viewer

Flag Viewer is an iOS application developed with UIKit and Swift. The app displays a list of country flags loaded from the application bundle. Users can select a flag to view it in detail and share it using the iOS share sheet.
Features
Display a list of country flags using UITableViewController
Load flag images from the app bundle
Navigate to a detail screen with UINavigationController
Show the selected flag in a larger UIImageView
Share a flag image using UIActivityViewController
Responsive layout created with Auto Layout

Technologies

Swift
UIKit
UITableViewController
UINavigationController
UIImageView
Auto Layout
UIActivityViewController
